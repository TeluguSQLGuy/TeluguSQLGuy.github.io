# TeluguSQLGuy Website — MVP

A responsive, static website for TeluguSQLGuy. Built with HTML, CSS and vanilla JavaScript so it can be hosted directly on GitHub Pages without a build step.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Create a public repository named **`TeluguSQLGuy.github.io`** under the `TeluguSQLGuy` GitHub account.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After deployment, visit **https://telugusqlguy.github.io/**.

## Customize

- Update lesson titles and direct YouTube URLs in `index.html`.
- Add new learning paths by duplicating an `<article class="path-card">` block.
- Change colors and layout in `styles.css` under `:root`.
- Update channel and GitHub links if they change.

## Current MVP scope

- Responsive homepage
- SQL, Snowflake, DBT and Data Engineering learning paths
- Latest lessons section
- About and social links
- Mobile navigation

The lesson cards currently link to the channel or course playlist. Replace them with individual video URLs as you publish content.
