## 📚 What You Will Find Here

* **SQL Basics:** Core concepts covering SELECT statements, WHERE clauses, filtering, and sorting.
* **Intermediate Queries:** Grouping data, aggregate functions, and mastering Joins (Inner, Left, Right, Full).
* **Advanced SQL:** Window functions, Subqueries, Common Table Expressions (CTEs), and Indexing.
* **Interview Preparation:** Real-world SQL interview questions asked by top tech companies, solved step-by-step.
* **Sample Databases:** Ready-to-run `.sql` dummy data sheets (E-commerce, HR, Banking) to practice at home.

---

## 🛠️ How to Use These Resources

1. **Find the Topic:** Browse our repositories to match the YouTube video you are currently watching.
2. **Clone or Copy:** Download the `.sql` scripts or copy the queries directly into your local database tool (like MySQL Workbench, SSMS, or PostgreSQL).
3. **Practice:** Run the queries yourself, modify the parameters, and experiment with the data!
